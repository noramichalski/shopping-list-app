# Shopping List App

A minimal shopping list built with HTML, CSS, and vanilla JavaScript.

[Live Demo](https://noramichalski.github.io/shopping-list-app/)

## Features

- Add items
- Mark items as completed
- Delete items
- Save and load list from `localStorage`
- Keyboard support (Return/Enter to add)
- Styled to match design spec
